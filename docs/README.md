## Documentation rules

1. Document only what exists or mark it as a recommendation.
2. Preserve original learning files and assignment context.
3. Use safe, synthetic inputs and outputs in examples.
4. State package, browser, operating system, database, and network prerequisites.
5. Avoid embedding large copied third-party content in Markdown.
6. Distinguish runnable source from reference documents, media, archives, and generated outputs.
7. Verify all links and Mermaid blocks before merging.
