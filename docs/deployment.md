# 🚢 Deployment and distribution

## No global deployment target

AT_LearnHub is a source and learning-material archive. It has no application server, website build pipeline, container definition, shared runtime, or production deployment process.

## Distributing learning material

- Share the repository or a topic-specific folder.
- Keep original source context and assignment descriptions.
- Include instructions for installing only the required tools.
- Verify all files are redistributable.
- Do not distribute secrets, private datasets, user profiles, or unverified executables.
- Keep large binary course material when it is part of the archive, but consider Git LFS or external storage for future large additions where appropriate.

## Turning an exercise into an application

A standalone project extracted from this archive needs its own product scope and system architecture, runtime and dependency manifest, configuration and secret handling, test suite and CI, security/privacy review, deployment/runbook, and license/attribution review.

Do not treat the repository as deployable merely because it contains code.
