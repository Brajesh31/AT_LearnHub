# 📖 Glossary

| Term | Meaning |
|---|---|
| Assignment | A task with instructions and expected deliverables |
| Browser driver | Executable that connects Selenium to a browser |
| CSV | Comma-separated tabular data format |
| DDL | Data Definition Language, such as CREATE TABLE |
| DML | Data Manipulation Language, such as INSERT/UPDATE/DELETE |
| Explicit wait | Wait that checks a defined browser condition |
| Exercise | Small practical task focused on a concept |
| Git working tree | Files checked out from the current commit plus local changes |
| Locator | Selenium strategy for identifying a page element |
| ODT | OpenDocument Text document format |
| ODS | OpenDocument Spreadsheet format |
| ORM | Object-relational mapping |
| QA | Quality assurance |
| SQL schema | Named collection of database objects |
| Test case | Steps, inputs, and expected outcome used to verify behavior |
| Web scraping | Extracting information from web resources |
| WebDriver | Selenium interface for controlling a browser |
