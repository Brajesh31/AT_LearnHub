# 🧭 Learning path catalog

Use these guides to navigate the archive. They are suggested sequences based on the topics visible in the repository, not a claim that every subject has complete lessons or assessments.

| Track | Suggested order | Guide |
|---|---|---|
| Python | Fundamentals → collections → control flow → functions/OOP → practice | [Python](python.md) |
| Linux | Shell orientation → filesystem → commands → scripts | [Linux](linux.md) |
| Git | Repository basics → staging/commit → branches → collaboration | [Git](git.md) |
| SQL | Database/schema → SELECT → joins → aggregation → constraints | [SQL](sql.md) |
| QA | Quality concepts → test cases → execution → defect reporting | [QA](qa.md) |
| Selenium | Browser setup → locators → waits → interactions → data extraction | [Selenium](selenium.md) |
| Web scraping | HTTP/HTML basics → selectors → extraction → data validation | [Web scraping](web-scraping.md) |

## Learner recommendation

Complete one topic at a time. Read the assignment document before running a script, and record environment versions for examples that depend on browsers, databases, or external websites.
