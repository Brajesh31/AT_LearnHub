# 🌐 Selenium learning path

## Goal
Learn browser automation with Selenium through practice scripts and the Census assignment folder.

## Suggested sequence
1. Install Selenium and a compatible browser.
2. Create a WebDriver session and close it reliably.
3. Locate elements using stable selectors.
4. Use explicit waits instead of fixed sleeps where possible.
5. Interact with forms and navigation on permitted test pages.
6. Validate output and handle exceptions.
7. Keep browser setup configurable and avoid committed user-specific paths.

## Archive areas
- `Selenium/Practice/` contains standalone examples.
- `Selenium/ASSIGNMENT-4/` includes an assignment script, input CSV, JSON output, documentation, and a bundled driver.
- `Selenium/Docs/` contains reference materials.

## Safety
Some scripts target external sites. Do not automate real accounts, evade CAPTCHAs, or bypass access restrictions. Use an authorized test environment.
