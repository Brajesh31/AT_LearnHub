# 🧪 QA learning path

## Goal
Understand how to plan tests, record expected outcomes, execute test cases, and communicate defects.

## Suggested sequence
1. Read the assignment instructions under `QA/`.
2. Identify the test objective, scope, preconditions, and test data.
3. Write cases with unique IDs, steps, expected results, and actual results.
4. Execute with controlled data and record evidence safely.
5. Log defects with reproducible steps and severity/priority rationale.
6. Summarize coverage, blockers, and residual risk.

## Practice outcomes
- Distinguish test scenario, test case, defect, severity and priority.
- Create positive and negative test cases.
- Record reproducible defect reports.
- Map requirements to verification evidence.

Use the [QA test case template](../templates/qa-test-case.md).
