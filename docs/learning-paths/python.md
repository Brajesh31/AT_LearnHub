# 🐍 Python learning path

## Goal
Build familiarity with Python syntax, values, data structures, control flow, functions, and object-oriented programming through the existing scripts and assignment material.

## Suggested sequence
1. **Syntax and variables:** Start with files under `Python/Day-1/`, including the `Python-1` lesson folder.
2. **Values and operators:** Review casting, expressions, math functions, operator precedence, and operators.
3. **Strings and collections:** Explore the Day-2 string/list examples and Day-3 dictionary, set, and tuple exercises.
4. **Control flow:** Review conditional and looping statement examples under later day folders.
5. **Functions and OOP:** Continue with functions and class-based practice as available in the directory.
6. **Practice:** Complete the practice folder exercises and relevant assignment document.

## Running an exercise
```bash
python "Python/Day-1/Python-1/Variables.py"
```

## Learning outcomes
- Explain variable assignment and data types.
- Use operators and expressions.
- Manipulate strings, lists, tuples, sets and dictionaries.
- Write conditions and loops.
- Define and call functions.
- Read and debug a small Python script.

## Practice ideas
- Convert a value between string, integer and float.
- Count values in a list.
- Build a dictionary-backed contact sample using synthetic data.
- Write a function that validates a simple input.
- Refactor repeated statements into a helper function.

These are suggested exercises, not existing files unless linked in the repository.
