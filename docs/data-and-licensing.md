# 📦 Data, documents, media and licensing

## Content categories
The repository includes office documents, datasets, SQL seed data, text files, archives, video, JSON outputs, and browser executables. Not all of these necessarily originate with the repository maintainer.

## Review checklist
Before adding or redistributing an artifact:
- Identify its author/source and acquisition context.
- Confirm redistribution permission and license.
- Preserve required notices and attribution.
- Check for embedded personal information and metadata.
- Remove credentials, private identifiers, and confidential course/work data.
- Record data schema and collection date where relevant.
- Avoid duplicating large artifacts without a reason.

## Large assets
The repository contains large binary course files and driver executables. For future additions, consider Git LFS or an external resource link where appropriate. Do not rewrite history or delete existing content as part of ordinary documentation work.

## License distinction
The root MIT license applies to the repository's own material to the extent the maintainer has rights to license it. It does not override third-party ownership or the terms of documents, media, datasets, code, browser drivers, or packages.
