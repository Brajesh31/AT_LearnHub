# FAQ

## Is this one application?

No. It is a collection of learning exercises and supporting documents.

## Do I need every dependency?

No. Install only what the specific example requires.

## Can I run Selenium examples against any website?

No. Obtain permission, respect terms and robots policies, and never use real credentials or personal accounts.

## Why are there duplicate lessons and binary files?

The repository preserves course history, assignments, notes, media, and intermediate artifacts. Do not remove them as part of unrelated changes.
