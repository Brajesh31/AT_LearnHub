# ❓ Frequently asked questions

## Is AT_LearnHub a single application?

No. It is a collection of independent learning resources, scripts, assignments, data, and reference documents.

## Which file should I run first?

Choose a topic in [learning paths](learning-paths/README.md), then follow the exercise-specific prerequisites. There is no global entry point.

## Do I need every Python package?

No. Install dependencies only for the exercise you are running. Check local requirements files and imports.

## Why are there multiple browser-driver binaries?

The archive preserves past Selenium practice and assignment artifacts. Drivers are platform- and browser-version-specific. Verify them before use, and prefer a compatible managed driver.

## Can SQL scripts be executed directly?

Only on a disposable local database after reviewing the statements. Some scripts contain DROP DATABASE commands.

## Are all examples production-ready?

No. Many are beginner exercises, assignments, or experiments. They may contain hard-coded paths, external URLs, old selectors, or incomplete error handling.

## Can I add new topics?

Yes. Follow the contribution guide and add a topic index and learning path.

## Why are some filenames inconsistent?

The repository preserves historical course structure. Existing filenames are not automatically renamed during documentation improvements.
