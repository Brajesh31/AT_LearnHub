# 🆘 Support and help

## Before opening an issue
1. Identify the exact topic and file path.
2. Read the relevant learning path.
3. Confirm the language/tool version.
4. Follow the exercise's working-directory instructions.
5. Reproduce with safe sample data.
6. Remove personal data, credentials, and private URLs from logs.

## Include
- Exact file path.
- Operating system and language/tool version.
- Command used and working directory.
- Expected and actual behavior.
- Sanitized error output.
- Required dependencies and browser/database versions.

## Do not include
Passwords, tokens, private browser profiles, real user data, private datasets, or unlicensed course content.

This is a community learning archive and does not offer a production support SLA.
