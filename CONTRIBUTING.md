# Contributing

Organize new material under the closest topic directory and use descriptive filenames. Keep source examples small, runnable where practical, and accompanied by input/output notes when behavior is not obvious.

Do not commit passwords, tokens, private datasets, browser profiles, or unlicensed documents/media. Redact personal information from examples. For Selenium work, avoid automating real accounts or sites without permission. Validate changed Python files with `python -m py_compile` where feasible and document optional dependencies.
