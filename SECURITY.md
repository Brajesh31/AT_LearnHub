# 🔐 Security policy

## Repository scope
This archive contains scripts, datasets, browser automation, SQL setup files, office documents, archives, and executable browser-driver binaries. Not every historical artifact has been security-audited.

## Safe handling
- Never commit passwords, API tokens, private keys, cookies, browser profiles, or personal datasets.
- Review shell scripts and SQL before executing them.
- Run database scripts only on disposable databases.
- Verify browser driver origin, version, and integrity.
- Use Selenium only against authorized targets.
- Do not bypass CAPTCHAs, authentication, anti-abuse controls, or rate limits.
- Review archives before extraction.
- Do not run unknown binaries or downloaded scripts blindly.

## Reporting
Privately report exposed secrets, malicious content, or security issues through the maintainer's GitHub profile: <https://github.com/brajesh31>. Include the file path and sanitized reproduction details. Do not attach credentials or personal records.

## Third-party content
Documents, media, datasets, dependencies, and driver binaries may be subject to separate licenses and security advisories. Review provenance before reuse.
