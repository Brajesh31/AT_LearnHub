# Security Policy

This repository contains educational scripts and browser automation examples. Do not run them with production credentials or sensitive files. Report exposed secrets, unsafe automation, malicious content, or vulnerable dependencies privately to Brajesh Kumar through the [GitHub profile](https://github.com/brajesh31), including the path and safe reproduction steps.

Review third-party packages, browser drivers, downloaded archives, and external URLs before execution. Keep credentials in local environment configuration that is never committed.
